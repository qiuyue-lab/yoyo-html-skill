# 动画（按需）

动画用来让看不见的变成看得见的，不是装饰。

- 默认暂停，点击或带领模式才往前
- 复杂过程要有重播
- 过渡 ≤ 400ms；概念演示可以更长，但要有节奏
- 用 `transform` / `opacity`，不用改宽高做动画

模板已提供：站点进入时的淡入、`data-step` 逐条出现、带领模式下的聚焦。

---

## 这一站该不该上动画

| 认知动作 | 用 | 不用 |
|---|---|---|
| 建立类比 | 左右对应逐条亮、再画连线 | 两段文字并排 |
| 展示过程 | 状态从 A 变到 B | 一张静态流程图 |
| 对比 | 先同时出现，再高亮差异 | 两张卡片各写一段 |
| 框架 | 从散落到归位 | 直接摆好的 2×2 |
| 情绪钩子 | 大字即可 | 不要为了动而动 |

精确数字、专有名词、步骤名用 HTML 写出来，不要写进 YoYo 图里做动画。
