# 怎么分成章

> Step 2 用。这是写作提纲，不是页面目录。不要把下面每一行做成一个 `<section>`，更不要做成左侧的一项。

一篇只分 3 到 5 章。章与章之间读者能感到话题变了。章内部是接得上的段落。

## 三种常见的篇章

**把一个判断讲清楚**（通常 3 章）

- 他们原来以为的，和你要挪动的那一点
- 这个判断怎么成立：机制、一个正例、它在哪里失效。这些是同一章里的连续段落，不是三页
- 现在能做的一件事，加上离开页面的链接

**带着做一件事**（通常 4 章）

- 做完手上留下什么
- 一个已经做完的小例子
- 做法本身。步骤是这一章里的列表或依次出现的句子，不是「一步一页」
- 对照：缺了哪一步，就回到上面哪一段

**一篇文章的伴读**（通常 3 章）

- 这篇文章真正在说的那一句
- 两三个认知转折，每个转折是一段话，其中一两处旁边有图
- 若要接着做：链接

不要安排「封面、讲师介绍、议程、致谢」。那是一场活动的程序单，读起来每一项都是断开的。

## 段落用什么形状

形状是为了读，不是为了凑满一块版面。一段里通常只有一种，而且多数段落就是标题加两三句，没有主视觉。

| 什么时候 | 用 |
|---|---|
| 开篇的那一句 | 大标题。图若有，缩在句子旁边 |
| 两样东西的差别 | 并排的两栏，差在颜色上 |
| 一个做法的步骤 | 纵向的几步，带领时可以逐条出现 |
| 一个框架的几块 | 两三张卡片。超过四块就还没想清楚 |
| 要人动手 | 一个题，能点、能选、能填 |
| 要离开页面 | 一句收束加链接 |

`st-figure` 这种「整段为了放一张图」的版式不要用。图没有自己的段落，它属于某一句。

## 一段里放什么

放：这一段要让人发生的那一点。需要结构时才用栏、步骤、卡片。

不放：这一段的讲稿、第二个隐喻、为了对称而加的第二块视觉。
