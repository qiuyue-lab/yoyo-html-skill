# 风格 DNA

一句话：纯白、极简、手绘、留白、克制、怪诞、产品草图感、中文手写感。结构清楚，但不是说明书。

## 必须

- 16:9 横版
- 纯白背景：不要米色、纸纹、渐变、阴影、噪点（白底进 HTML 后由页面把纸色融进去）
- 黑色手绘线稿：细线、轻微抖动，不机械
- 大量留白：主体 40%–60%，至少 35% 空白
- 少量中文手写批注：最多 5–8 处，每处 2–8 个字
- 一张图只讲一个核心动作 / 结构 / 状态 / 隐喻
- YoYo 必须参与核心动作

## 颜色

- 黑：线稿、结构、主要文字
- 黄：YoYo 的膝盖长度连衣裙（固定识别色）
- 红：重点批注
- 橙：主流程、路径、箭头
- 蓝：补充说明

## 绝对不要

- 商业插画、PPT 信息图、正式流程图、课程课件脸
- 可爱卡通海报、儿童插画
- 科技感 UI、真实 App 截图、写真贴图
- 复杂背景
- 左上角写「流程图 / 系统架构图 / 常见坑」这类标题
