# YoYo IP

YoYo 是 TeacherYo 的固定视觉角色。不是写真贴图，是从本人外形提炼出的手绘小人——在画面里承担核心动作。

真人参考图可以用于生成，也可以随作品传播。但生成结果必须是手绘，不许把照片贴进画面。

## 外形（必须遵守）

- 发型：齐肩偏短的红棕色头发，有短刘海
- 裙装：明黄色无袖宽松连衣裙，下摆到**膝盖**即止。不要及踝、拖地、配裤子
- 体型：修长、轻盈，动作舒展，像正在做事
- 画法：黑色细线手绘轮廓 + 少量平涂（黄裙子为主）
- 表情：自然、有神、带一点轻快笑意。不要 deadpan 空脸
- 比例：白板产品草图人物，不是 Q 版

## 性格与动作

YoYo 必须参与画面的核心动作，不能只站在角落。
像一个正在认真处理某个荒诞但成立的隐喻的工作者。怪诞、清爽，不幼稚。

判断：去掉 YoYo，图的核心隐喻还能完全成立 → YoYo 太装饰，重写提示词。

## 禁止

- 写真、3D、精致商业插画
- 过度可爱、儿童卡通
- 黄色裙装消失或裙子长度漂移
- 只当旁观者
- 把真人照片直接贴进画面
