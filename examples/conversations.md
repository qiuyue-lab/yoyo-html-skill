# 对话示例

## 1. 给了讲稿，直接做路径

用户：

```
用 yoyo-html-skill，把下面讲稿做成学习路径。
走完，新老师要能把「让 AI 改作业」改成「让 AI 先看懂我的班」。
（粘贴讲稿）
```

Agent 应做：

1. 不追问风格
2. 选叙事结构，写成 3 到 5 章的提纲。章里面是接得上的段落，不要输出一行一个动作的编号表
3. 复制 `template/journey.html`，按章改，不要按讲稿的每个要点各做一节
4. 在两三处转折旁写 `yo-fig`，图是那一句的批注，然后生成
5. 讲稿进 notes

---

## 2. 只有一句指令

用户：

```
做一页给教研员走的 HTML。主题：为什么先改提问，再让 AI 出题。
要能点进我已经做好的任务页 task.html。
```

Agent 应做：

1. 问「走完要能做什么」（若用户已说，就跳过）
2. 按「把一个判断讲清楚」写成大约 3 章
3. 在读者要动手的那一段插入 `task.html` 链接
4. 核心判断那一句旁边生一张 YoYo 图

---

## 3. 已有 HTML，只加一张图 / 一个链接

用户：

```
「别人用得了」这一段旁边加一张图：老师把方向盘握在自己手里。
再在这段底下加链接到 https://...
```

Agent 应做：只改这一段。按 `references/components.md` 把图放进 `.beat`，链接用 `a.btn`，生成那一张，回填 src。不要重做整篇。

---

## 4. 先出结构，不要生成

用户：

```
先不要做页面。看这篇口播，告诉我分成哪几章、哪几句旁边配 YoYo。
```

Agent 停在篇章提纲，标哪几句用图。等用户说「做」再进 Step 4。
