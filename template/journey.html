先停一下

他们点头了，不代表能走下一步。

这不是一页一页往后翻的课件。这是一条学习路径：一站一个认知动作，走完要能做事。

开场不要解释模板。先让对方感到「听懂」和「能走」的差别。

下一步：你原来怎么想 →

你是在「放映」，还是在「带着走」？

放映

一页一个标题。听众跟着你的遥控器走。走完，他们记得封面，不记得自己下一步点哪里。

带着走

一站一件事。人可以自己滚，也可以被你一步一步揭开。中间随时能点开工具，离开页面也能继续做。

让对方自己对号入座。不要在这里开始讲 skill 目录。

下一步：核心判断 →

只要记住一件事

把散落的想法，收成一个结构。

精确的字写在 HTML 里。图只负责这一个动作，贴在句子旁边，不要铺成一张海报。

强调：不是每站都配图。这张图是认知锚点，不是装饰。

下一步：三种材料 →

一站里只有三种材料。

A
结构用 HTML / SVG。框架、对比、数字、步骤——文字不能错的，不要画进图里。
B
隐喻用 YoYo 图。封面、转折、情绪。一条路径里大约 3–6 张，不要站站都生图。
C
出口用链接。任务页、工具、下一篇。点它，人应该能离开这里去做事。
示范占位插槽。真正生成时回填 src。

下一步：试一试 →

下面这段话，更像哪一种站点？

「今天我们讲三个原则：以学生为中心、数据驱动、因材施教。」

更像放映。要变成站点，得改成一件能做的事——比如「把这三条收成一个提问，去问你的班」。出口是那一个提问，不是三条原则。
点完再讲。正确答案是第一个。

下一步：带走 →

离开之后

把讲稿丢进来，从这份骨架开始改。

复制本文件。改各站。认知转折处写 YoYo 插槽。链接随时插。不要把它改回翻页课件。
