# 构图

每张图只选一个结构类型。

| 类型 | 适用 |
|---|---|
| 前后对比 | 过去 vs 现在、两种逻辑 |
| 概念隐喻 | 抽象判断需要物理化 |
| 角色状态 | 人处在张力或悖论中 |
| Workflow | 信息/流程的传递与变形 |
| 系统局部 | 三角、双主体、分层 |
| 方法分层 | 几个原则并列但有关联 |
| 地图路线 | 阶段路径 |
| 小漫画分镜 | 2–3 格轻量叙事 |

## 发明隐喻

1. 从这一站里找一个**动作**或**物件**，不要找抽象词
2. 低科技、怪诞但成立：绳子、箱子、桥、漏斗、虚线轮廓
3. YoYo 必须正在做这个动作
4. 不要复用旧文章的构图

## YoYo 常见动作（启发，不要照抄）

- 拉线，把散落的点收进一个箱子
- 站在「现在」和「下一步」的边界上铺木板
- 量一个还不存在的虚线轮廓
- 在三角关系里承担第三个角
- 被气泡包围，但只往一个方向走
